  1. 单 Skill在选定 Agent 的系统提示词中加入一个 Skill，观察对应任务和其他任务的效果。

两种数据有什么区别？

SFT：先教会模型正确做法

每条数据是一段完整对话，包含问题、正确工具、参数、工具返回和最终答案。

DPO：再让模型偏好正确做法

每条数据包含同一问题下的一好一坏两条动作序列，让模型减少已观察到的错误。
